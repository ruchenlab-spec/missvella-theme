# Hero Slideshow · 堆叠

2026-11-06 新增，已精确部署到线上主题 Missvella Dev（`167137378374`）。

## 编辑器配置

1. 刷新主题编辑器，点击「添加分区」，搜索 **Hero Slideshow · 堆叠**。
2. 默认生成 5 个图片区块，可增加、删除、排序，最多 12 张。
3. 每个区块选择图片；可另选移动端图片，并填写图片描述、标题、链接及链接文字。
4. 分区可调页面宽度／全宽、配色、桌面／移动端图片最大高度、初始重叠程度、圆角、动画时长和间距。标题可留空。
5. 由商家保存分区实例及图片配置。部署代码不会自动往页面添加分区。

## 交互与布局

- 初始按图片原始宽高比计算宽度，再依容器宽度和图片数量计算重叠位置。图片保持比例完整展示；宽图按可用宽度等比例缩小，所以「图片最大高度」不代表所有图片等高。
- 悬停图片时，该图完整展示并置于顶层，左侧图片向左滑动、右侧图片向右滑动。其他图片保留可点选的边缘，宽图也会为两侧预留空间。
- 鼠标移出且分区内没有键盘焦点时恢复初始堆叠。点击或键盘聚焦后可保持选中；选中的图片显示可选标题和链接。
- 手机可点击图片露出的部分或使用下方公共圆形箭头。图片较多时露出边缘会较窄，可通过箭头逐张查看。
- 聚焦图片后支持左右方向键、Home／End；Escape 收回堆叠。减少动态效果偏好会关闭过渡。
- 在编辑器选中图片区块，会展开对应图片；取消选中后收回。分区重载／移除会清理观察器及事件监听。
- 只有一张图片时居中展示并直接显示可选标题／链接，不显示翻页控件。
