# Hero Slideshow · 堆叠

2026-11-06 新增，已精确部署到线上主题 Missvella Dev（`167137378374`）。

## 编辑器配置

1. 刷新主题编辑器，点击「添加分区」，搜索 **Hero Slideshow · 堆叠**。
2. 默认生成 5 个图片区块，可增加、删除、排序，最多 12 张。
3. 每个区块选择图片；可另选移动端图片，并填写图片描述、标题、链接及链接文字。
4. 在某个图片区块勾选「设为主要优先图片」。未勾选时使用第一张；多张勾选时使用区块顺序最靠前的一张。
5. 分区设置新增「显示翻页按钮」（默认开启，关闭后连同页码隐藏）及「主要优先图片展示宽度」（20%–100%，默认 100%）。百分比以该图片正常完整展示宽度为基准，调小后保持比例缩小，不裁掉图片内容。
6. 分区可调页面宽度／全宽、背景颜色、文本颜色、桌面／移动端图片最大高度、堆叠重叠程度、圆角、动画时长和间距。颜色留空时跟随全局配色，背景改变后复用主题自动文字对比度处理。标题可留空；重叠程度仅在空间不足时生效。
7. 由商家保存分区实例及图片配置。部署代码不会自动往页面添加分区。

## 交互与布局

- 按图片原始宽高比计算宽度，再应用优先图的宽度百分比。容器放得下所有图片时居中完整平铺，图片间距最多 16px，空间紧张时先缩小间距；只有图片总宽度超过容器时才堆叠。宽图按可用宽度等比例缩小，所以「图片最大高度」不代表所有图片等高。
- 堆叠时默认完整展示主要优先图片，其余图片保留可点选的边缘。悬停其他图片时，该图完整展示并置于顶层，左右图片向两侧滑动。完整平铺时悬停不改变图片位置，所有图片的标题／链接均可用。
- 鼠标移出且分区内没有键盘焦点时恢复优先图片。点击或键盘聚焦后可保持选中；堆叠时选中的图片显示可选标题和链接。
- 手机可点击图片露出的部分，或在开启翻页按钮时使用下方公共圆形箭头；翻页从当前图片或主要优先图片继续。
- 聚焦图片后支持左右方向键、Home／End；Escape 恢复优先图片。减少动态效果偏好会关闭过渡。
- 在编辑器选中图片区块，会展开对应图片；取消选中后恢复优先图片。分区重载／移除会清理观察器及事件监听。
- 只有一张图片时居中展示并直接显示可选标题／链接，不显示翻页控件。
